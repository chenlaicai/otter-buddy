# 删旧机制前：保护接管检查表

删除或替换既有机制、保护、默认路径时填写；纯文档措辞调整不必填。它把「旧契约/原路径约束」具体化，不新增审批人或常驻任务。

| 被删/替换物 | 原保护的不变量全集（含双向状态迁移、异常路径） | 原消费者（运行时/观测/测试/文档） | 新机制如何接管；不接管则显式风险接受 |
|---|---|---|---|
| | | | |

填写纪律：
- **按机制/路径逐行枚举**，不能只写「无影响」「更简」「净删除」。不变量同时核对正向与反向状态迁移、失败/超时/空输入等异常路径。
- **消费者不只数直接调用方**：运行时入口之外，逐项核对观测/分类器、测试/mock、文档/运维；找不到消费者要写明检索依据，不把「没搜到」当「不存在」。
- **接管落到具体新路径**：写明新机制在哪一层保留哪条不变量；确无接管时写残余风险、影响面与明确风险接受，不以删除行数少替代论证。
- 表随本特性方案/自检记录交付；检视者在正确性维度对照 diff 核对完整性，证据不足标「证据不足」，不把有表等同于填对。
