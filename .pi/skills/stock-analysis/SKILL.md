# Stock Analysis

基于 `stock_data` 工具的 A 股+港股个股分析能力。数据分析与操作参考，不构成投资建议。

## 触发

**触发条件**：搭档要求查看或分析个股数据（A 股或港股）——看盘、分析个股、复盘、盯盘、查行情。

**排除**：通用数据查询（非股票）→ `core-workflow`。闲聊讨论 → `companion`。

**输入**：
| 输入 | 必选 | 缺失时 |
|------|------|--------|
| 股票代码或名称 | 是 | 停下来问搭档。名称需先确认代码 |
| 分析范围 | 否 | 默认全面分析（基本面+技术面+消息面+资金面） |

## 工具调用指引

所有数据通过 `stock_data` 工具获取（封装于 `scripts/stock-cli.py`，基于 akshare）。

| 命令 | 用途 | 关键参数 | 分析维度 |
|------|------|----------|----------|
| `kline` | A 股日 K 线数据 | `code`(6位), `days`(默认120), `adjust`(qfq/hfq/""), `no_cache` | 技术面：趋势、位置、量能 |
| `overview` | A 股基本信息+实时行情+估值 | `code`(6位), `no_cache` | 基本面：PE/PB/市值/行业 |
| `finance` | A 股财务指标 | `code`(6位), `quarter`(默认4), `no_cache` | 基本面：营收/净利/ROE/毛利率 |
| `news` | 个股新闻（A/港股通用） | `code`(6位或5位), `limit`(默认10), `no_cache` | 消息面：公告/事件/舆情 |
| `northflow` | 北向资金汇总 | `no_cache` | 资金面：外资动向 |
| `hkline` | 港股日 K 线数据 | `code`(5位如01810), `days`(默认120), `no_cache` | 技术面：趋势、位置、量能 |
| `hvaluation` | 港股估值（PE-TTM/PB 三年百分位） | `code`(5位), `no_cache` | 基本面：估值分位 |

**调用策略**：
- A 股全面分析：依次调用 overview → finance → kline → news → northflow（5 命令）
- A 股快速查看：只调 overview + kline（2 命令）
- 港股全面分析：依次调用 hvaluation → hkline → news（3 命令）
- 港股快速查看：只调 hvaluation + hkline（2 命令）
- 消息追踪：只调 news + kline/hkline（2 命令）
- 调用失败时报告错误，不静默跳过——数据缺失必须在分析中标注

## 工作流

1. **确认目标**：明确股票代码和分析范围。名称不明确时先问搭档确认代码。
2. **数据采集**：按分析范围调用 `stock_data` 命令。数据缺失时标注原因（接口异常/网络超时/代码不存在）。
3. **基本面分析**（overview + finance）：
   - 估值水平：PE/PB 与行业均值对比（无行业数据时标注）
   - 盈利能力：营收增速、净利润增速、ROE、毛利率趋势
   - 市值规模：大盘/中盘/小盘定位
4. **技术面分析**（kline）：
   - 趋势判断：MA5/MA20/MA60 排列关系（多头/空头/缠绕）。注意：MA60 需要至少 60 根 K 线，days<60 时 MA60 缺位——快速复盘建议 days≥60
   - 位置判断：当前价相对区间高低点位置
   - 量能分析：成交量趋势（放量/缩量/平稳）
   - 波动率：近期波动幅度与历史对比
5. **消息面分析**（news）：
   - 近期重要事件：公告、业绩、政策影响
   - 舆情倾向：正面/负面/中性
   - 与技术面的交叉验证：消息是否解释了价格异动
6. **资金面分析**（northflow）：
   - 北向资金整体流向
   - 与个股走势的关联性（如有）
7. **综合结论**（四层呈现）：
   - **事实层**：数据直接反映的情况（价格、估值、财务指标）
   - **推断层**：基于数据的合理推断（趋势方向、估值区间判断）——标注推断依据
   - **风险提示**：当前主要风险因素
   - **操作参考**（必须可执行）：
     - 每条建议必须含：触发条件 + 动作 + 止损位。示例：「稳健者：跌破前低 21.3 止损；激进者：放量站上 MA60 再加仓」
     - 按风险偏好分层（稳健/激进），不是单点喊买卖
     - 价位必须来自本次分析的实际数字，不发明价格
     - 禁止空泛表述：「建议关注」「需谨慎」「有风险」不算操作参考
   - 数据时点：以 kline/hkline 返回的最后一根 K 线日期作为整个分析的数据截止时间，所有结论标注该日期

## 产出

| 产出 | 下一步 | 执行者 |
|------|--------|--------|
| 结构化分析报告 | 搭档确认 / 深入讨论 | 搭档 |
| 数据异常报告（如有） | 记录到 memory 或 issue | 当前獭 |
