# slides 工具链约定

> 使用时机：演示产物落地时。两条产出路线，按交付场景选择。

## 路线选择

| 场景 | 路线 | 约定 |
|---|---|---|
| 对话内展示/快速分享 | HTML slides | 单文件自包含，键盘翻页（方向键/空格），浏览器全屏即放映 |
| 正式交付（要 .pptx 文件） | pptxgenjs 类库生成 | 代码生成 .pptx，母版约定落在代码常量里 |

## HTML slides 约定

- 单文件：所有页内联在一个 HTML，`<section class="slide">` 逐页，JS 捕获键盘翻页
- 页面尺寸锁定 16:9（1280×720 基准），字号按「后排可读」校准（正文等效 ≥18pt）
- 母版三版式（标题页/内容页/章节页）用 CSS 类统一，禁止逐页手调
- 断言标题（assertion headline）落在 HTML 语义里（h1/h2 层级即主张层级）

## pptx 生成约定

- 用 pptxgenjs（或同类）代码化生成——母版/主题色/字体作为代码常量集中定义，改风格=改常量
- 交付物：.pptx 源文件 + 生成脚本（可再生成）
- 图表用原生 chart 对象（可编辑），不用截图贴图

## 与其他媒介工具链的关系

- 共享色彩纪律（锚点变量化）与字体策略（系统栈模拟配对意图）
- 特有纪律：**放映环境校准**（字号/对比度按投影场景校验，非屏幕阅读标准）；**页序-主张表先行**（叙事结构先于视觉，structure.md 的交付物）
