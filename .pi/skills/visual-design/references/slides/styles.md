# slides 风格词典 v1（词典+人择）

> 使用时机：design/redesign 处理演示类 brief 的第 3 步。
> slides 特化：远距离可读性（会议室投影）+ 母版一致性（一套字体色彩系统贯穿全片）权重高于单页表现力。

## 人择协议

同 web/poster 词典：2-3 候选+人择+推到位。slides 的「推到位」额外含义：选定风格做成**母版级约定**（标题页/内容页/章节页三种版式的字体字号色彩），不是每页即兴。
