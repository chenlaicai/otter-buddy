# slides 反泔水清单与质检门（不过门不出稿）

> 使用时机：演示产物交付前最后一道闸。audit 动词以本清单为评分依据。

## 质检门流程（三步强制）

同 web/poster：反模式扫描 → 自我批评（「这套 slides 哪里像 AI 生成的？」）→ 出门说明（叙事弧选择理由 + 母版贯彻自查 + 命中项处置）。无说明=没过门。
**全片级检查先于单页级**：先审页序-主张表，再逐页扫。

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 |
|---|---|---|
| S1 | 页序无叙事 | 页与页无推进逻辑（素材堆放序，非叙事序） |
| S2 | 单页多任务 | 一页塞 2+ 论点，标题写不出一句话主张 |
| S3 | 母版漂移 | 页间字体/色彩/版式不统一（每页即兴） |
| S4 | bullet 堆砌 | 每页都是项目符号列表，无层级无图形化表达 |

### 观察项（记录处置）

| # | 反模式 | 症状 |
|---|---|---|
| T1 | 模板感 | 默认主题模板痕迹（自带配色+默认版式） |
| T2 | 假图表 | 装饰性图表（无数据支撑的饼图/上升箭头） |
| T3 | 字超载 | 单页 >50 字或 >5 行 bullet |
| T4 | 图标凑数 | 每个标题配图标，无信息增量 |
| T5 | 动画滥用 | 与内容无关的飞入/旋转动画 |
| T6 | 结尾塞料 | 最后一页堆新信息而非收束 |
| T7 | 字号过小 | 正文 <18pt 等效（会议室后排不可读） |
| T8 | 低对比 | 灰底灰字、装饰性渐变底上放字 |

## audit 评分输出格式

```
## slides 泔水分体检报告
叙事层：[弧线清晰/素材堆放] —— 一句依据
母版层：[一致/漂移] —— 一句依据
观察项：T3 命中（……）……
致命项：S2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行，修复走 redesign。
