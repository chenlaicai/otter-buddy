# slides 反泔水清单与质检门（不过门不出稿）

> 使用时机：演示产物交付前最后一道闸。audit 动词以本清单为评分依据。
> 每项附**判定操作**。全片级检查先于单页级。

## 质检门流程（三步强制）

同 web/poster：反模式扫描（按判定操作）→ 自我批评（「这套 slides 哪里像 AI 生成的？」）→ 出门说明（叙事弧选择理由 + 母版贯彻自查 + 命中项处置）。无说明=没过门。
**顺序纪律**：先审页序-主张表（叙事层），再逐页扫（母版层/单页层）。

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| S1 | 页序无叙事 | 页与页无推进逻辑 | 写出每页一句话主张连读——读不成连贯论证/故事（有页无法归入叙事弧阶段）= 命中 |
| S2 | 单页多任务 | 一页塞 2+ 论点 | 该页标题无法写成一句话主张，或正文含 2+ 独立结论 = 命中 |
| S3 | 母版漂移 | 页间字体/色彩/版式不统一 | 抽查第 2/中间/倒数第 2 页的 font-family、主色、标题位置——任一不一致 = 命中 |
| S4 | bullet 堆砌 | 每页项目符号列表无层级 | 连续 3+ 页主体都是同构 bullet 列表（每条同级）= 命中 |

### 观察项（记录处置）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| T1 | 模板感 | 默认主题模板痕迹 | 存在 Office/Google 默认主题的版式与配色（未按词典词条重建）= 命中 |
| T2 | 假图表 | 装饰性图表无数据支撑 | 图表删掉后论证无损，或数据无出处 = 命中 |
| T3 | 字超载 | 单页文字过多 | 单页正文 >50 字或 bullet >5 行 = 命中 |
| T4 | 图标凑数 | 标题配图标无增量 | 同 web B3：删图标信息无损 = 命中 |
| T5 | 动画滥用 | 与内容无关的动画 | 存在无语义的飞入/旋转/弹跳（用于强调逻辑或引导注意力的除外，需说明）= 命中 |
| T6 | 结尾塞料 | 末页堆新信息 | 最后 1 页含前文未出现的论点/数据（致谢页/结论复述不算）= 命中 |
| T7 | 字号过小 | 后排不可读 | 正文等效字号 <18pt（HTML 1280×720 基准下 <24px）= 命中 |
| T8 | 低对比 | 灰底灰字/渐变底放字 | 文字与背景对比度 WCAG 估算 <4.5:1 = 命中 |

## audit 评分输出格式

```
## slides 泔水分体检报告
叙事层：[弧线清晰/素材堆放] —— 一句依据（引 S1 判定结果）
母版层：[一致/漂移] —— 一句依据（引 S3 判定结果）
观察项：T3 命中（……）……
致命项：S2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行，修复走 redesign。
