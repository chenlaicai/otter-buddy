# poster 反泔水清单与质检门（不过门不出稿）

> 使用时机：海报/单帧产物交付前最后一道闸。audit 动词以本清单为评分依据。
> 每项附**判定操作**——机械可执行，自评照做。

## 质检门流程（三步强制）

同 web：反模式扫描（按判定操作逐项）→ 自我批评（「这海报哪里像 AI 生成的？」至少找一个弱点处置）→ 出门说明（构图选择理由 + 风格贯彻自查 + 命中项处置）。无说明=没过门。

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| P1 | 居中大字+光晕 | 标题居中+发光+渐变底 | 标题存在 text-shadow/radius 发光效果，或背景渐变+文字居中同时成立 = 命中（词典选定含光效的风格除外） |
| P2 | 信息堆砌 | 无层级纪律，元素抢注意力 | 非内容像素（留白）占比 <15%，或找不到一个视觉安静区 = 命中 |
| P3 | 风格贴皮 | 主视觉有风格，细节层默认 | 检查细节层（主办方/二维码/长文案区）——样式与主视觉不属于同一词条系统 = 命中 |
| P4 | 模板同构 | 与近期海报抹色后无差异 | 去色对比近期海报的构图分区（动线/主体位置/留白分布）——分区相同 = 命中 |

### 观察项（记录处置）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| Q1 | 假设计感渐变 | 无来由紫蓝渐变底 | 背景渐变主色不在选定词条的色彩锚点内 = 命中 |
| Q2 | 图标凑数 | 装饰图标无信息增量 | 删除全部图标——信息无损 = 命中 |
| Q3 | 字号无跨度 | 主次文字接近大小 | 最大字号 ÷ 正文字号 <4 = 命中（海报健康区间 5-10 倍） |
| Q4 | 居中强迫 | 一切居中无视动线 | 全部元素水平居中，未采用 Z/F/对角/散点任何动线 = 命中 |
| Q5 | 字体超载 | 3+ 字体家族 | font-family 家族数 >2 = 命中 |
| Q6 | 色彩超载 | 5+ 色相无主次 | 统计色相数（排除灰阶）：>3 个且最大面积色占比 <50% = 命中（单帧阈值比 web 的 4 更严——海报无滚动纵深，克制要求更高） |
| Q7 | 假纹理 | 贴噪点/网格与风格无关 | 纹理效果在选定词条特征中无出处 = 命中 |
| Q8 | 二维码孤立 | 二维码突兀破坏构图 | 二维码尺寸 > 细节层其他元素，或超出构图安全边距 = 命中 |

## audit 评分输出格式

```
## 海报泔水分体检报告
构图层：[动线清晰/堆砌] —— 一句依据（引 P2/Q4 判定结果）
风格层：[贴皮/贯彻] —— 一句依据（引 P3 判定结果）
观察项：Q1 命中（……）……
致命项：P2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行，修复走 redesign。
