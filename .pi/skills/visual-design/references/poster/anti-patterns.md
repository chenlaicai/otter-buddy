# poster 反泔水清单与质检门（不过门不出稿）

> 使用时机：海报/单帧产物交付前最后一道闸。audit 动词以本清单为评分依据。

## 质检门流程（三步强制）

同 web：反模式扫描 → 自我批评（「这海报哪里像 AI 生成的？」至少找一个弱点处置）→ 出门说明（构图选择理由 + 风格贯彻自查 + 命中项处置）。无说明=没过门。

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 |
|---|---|---|
| P1 | 居中大字+光晕 | 标题居中+发光效果+渐变底——AI 海报第一标志 |
| P2 | 信息堆砌 | 无层级纪律，所有元素抢注意力，留白 <15% |
| P3 | 风格贴皮 | 选定风格只在标题区，细节层回归默认（图标框/圆角卡） |
| P4 | 模板同构 | 与近期产物抹掉颜色后无法区分（同样的居中三段式） |

### 观察项（记录处置）

| # | 反模式 | 症状 |
|---|---|---|
| Q1 | 假设计感渐变 | 无来由的紫蓝渐变背景（不是风格词典选定的） |
| Q2 | 图标凑数 | 装饰性图标/emoji 填充，无信息增量 |
| Q3 | 字号无跨度 | 所有文字接近大小，无主次（跨度应 5-10 倍） |
| Q4 | 居中强迫 | 一切居中，无视 Z/F/对角线动线 |
| Q5 | 字体超载 | 3+ 字体家族无配对逻辑 |
| Q6 | 色彩超载 | 5+ 色相无主次系统 |
| Q7 | 假纹理 | 表面贴噪点/网格但与风格系统无关 |
| Q8 | 二维码孤立 | 细节层二维码突兀大/位置破坏构图 |

## audit 评分输出格式

```
## 海报泔水分体检报告
构图层：[动线清晰/堆砌] —— 一句依据
风格层：[贴皮/贯彻] —— 一句依据
观察项：Q1 命中（……）……
致命项：P2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行，修复走 redesign。
