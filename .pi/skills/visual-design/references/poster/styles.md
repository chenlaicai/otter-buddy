# poster 风格词典 v1（词典+人择）

> 使用时机：design/redesign 处理海报类 brief 的第 3 步。给 2-3 个候选人择，选定后推到位。
> 与 web 词典的关系：共享设计史血脉但海报特化——单帧、无滚动、视觉冲击力权重高于信息效率。跨词典词条可互相引用。

## 人择协议

同 web 词典：2-3 候选 + 一句话特征 + 适用判断；词典无匹配时走 study 现场提取或共创，不硬凑；选定后推到位（贯彻到细节层，不只主视觉）。
