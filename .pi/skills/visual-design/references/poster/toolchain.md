# poster 工具链约定

> 使用时机：海报产物落地时。两条产出路线，按需求选择；同一项目内不混用。

## 路线选择

| 场景 | 路线 | 约定 |
|---|---|---|
| 文字/排版主导（通知/观点/信息海报） | HTML/SVG 单文件 | 单文件自包含，固定画布尺寸（如 1080×1528 竖版），浏览器打开即成品，可截图导出 |
| 插画/图像主导（主视觉/氛围海报） | 图像生成 prompt + 文字层分离 | 图像模型出底图，文字用 SVG/HTML 覆盖层——**文字不进图像生成**（AI 渲染文字易崩，文字层永远矢量可控） |

## HTML/SVG 约定

- 固定画布：根容器按目标尺寸锁定（px），不做响应式——海报是单帧定稿物
- 文字全矢量：真实文本节点，不用图片化文字（可编辑、可检索、清晰度无损）
- 导出：浏览器打开后截图或 print-to-PDF；交付物含源文件
- 色彩按词典锚点落到 CSS 变量（--ink/--accent 类），方便 redseign 换肤

## 图像生成 prompt 约定

- prompt 结构：[风格词条名] + 构图描述（动线+主体位置）+ 色彩锚点 + 「no text」（文字层分离纪律）
- 底图生成后必须过一次质检门（P1-P4/Q1-Q8）再进文字层合成
- 文字覆盖层用 SVG 绝对定位，字体配对按词典词条执行

## 与 web 工具链的关系

共享字体策略（系统栈模拟配对意图）与色彩纪律（锚点变量化）；差异点：海报无响应式、无交互、定稿物思维——一次成型，不留「后续迭代」预期。
