# 方法论本体：四层抽象（媒介无关）

> 本文是 visual-design skill 的原理层。方法论的业界溯源：AI 海报方法论（2026，HN 1784 分实证）与 hallmark / taste-skill / ui-ux-pro-max 设计 skill 生态（2026，头部 12 万星级）的共识蒸馏。四层抽象均不绑定媒介——海报的构图、UI 的布局、PPT 的叙事，都是各自媒介的具体化实例。

## 核心命题

**「结构化约束 > 端到端生成」**：一句话直出（端到端）产出的默认是模型的训练分布均值——即「泔水」（slop）：平庸、同质、可预测。质量来自分层施加约束：每加一层结构化约束，成品质质上一个台阶。这不是模型能力问题，是工作流问题。

## 四层抽象

### ① 结构层（信息先于视觉）

先定信息骨架，后谈任何视觉。骨架 = 叙事节奏（信息以什么顺序密度展开）+ 层级（什么最重要、什么折叠）+ 动线（受众的注意力路径）。

**为什么结构优先**：泔水感的根源多是结构性的（所有页面都是 hero→三特性→CTA→页脚的同构节奏），换颜色换字体救不了结构同质。两个不同 brief 的产物应该有不同的骨架，像不同的东西，而不是同一模板的换色。

### ② 风格层（词典+人择）

模型内置庞大的风格知识（设计史流派、印刷传统、当代趋势），但默认调用的是「最平均」的那部分。解法：

1. **借词典**：把风格做成可枚举可搜索的词典（名称/特征/字体配对/色彩锚点/适用场景），扩展选择空间
2. **人择**：人不需要设计史知识，只需要在候选中做品味判断——「认得出」哪个对
3. **推到位**：选定后深挖执行（push it properly, not superficially）——风格的价值在一致性贯彻，不在表面贴皮

### ③ 质检层（反泔水门禁）

生成后、交付前，强制过反模式检测：泔水特征清单逐项扫描 + 自我批评（「这个产物哪里像生成的？」）。不过门不出稿。

**为什么需要门**：模型的训练惯性会把它拉回分布均值——即使 prompt 里约束了风格，执行中仍会漂移回默认（居中、对称、渐变、图标堆砌）。质检门是对抗漂移的最后一道闸。

### ④ 交互层（四动词）

设计工作流不是只有「生成」一个动作：`design`（新建）/ `audit`（审视评分不改稿）/ `redesign`（保留内容换视觉层）/ `study`（从参考提取 DNA）。四动词覆盖设计工作流全周期，且边界清晰——audit 不改稿（诊断与执行分离），redesign 不动信息架构（视觉层与内容层分离）。

## 与媒介的关系

四层抽象是本体，各媒介提供三样具体物：**结构实例**（web=布局节奏 / 海报=单帧构图 / PPT=页序叙事）、**工具链**（web=HTML/CSS / 海报=SVG或图像生成 / PPT=slides 格式）、**泔水特征清单**（每媒介的默认套路不同）。新增媒介 = 新增这三样，本体不变。
