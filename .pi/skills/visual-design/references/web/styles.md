# web 风格词典 v1（词典+人择）

> 使用时机：design/redesign 动词的第 3 步。给搭档 2-3 个候选供人择，选定后推到位。
> 每条含**实现锚点**——选定后落地 CSS/HTML 的具体抓手，消灭「即兴发挥」段。

## 人择协议

1. 从下表选 2-3 个与 brief 匹配的候选（附一句话特征 + 你的适用判断）
2. 词典没有匹配项时：明示「词典无匹配」，走 study 流程从参考提取，或与搭档共创描述——不硬凑近义项
3. 选定后**推到位**：按词条的实现锚点执行，贯彻到每个角落；浅尝辄止=表面贴皮

## 词条增长机制

study 动词提取的 DNA 若有复用价值，按同格式增补（六要素：特征/字体/色彩/适用/**实现锚点**）才算完整词条。
