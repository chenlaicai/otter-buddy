# web 反泔水清单与质检门（不过门不出稿）

> 使用时机：design/redesign 产物交付前的最后一道闸。audit 动词以本清单为评分依据。
> 每项反模式附**判定锚点**——把主观判断转成可机械执行的判定操作，自评时逐项照做，不复凭感觉。

## 质检门流程（三步强制）

1. **反模式扫描**：下表逐项过**判定操作**，命中任何「致命项」直接返工，命中「观察项」逐条记录处置
2. **自我批评**：以「这产物哪里像 AI 生成的？」自问，至少找出一个弱点并处置（修掉或写明豁免理由）
3. **出门说明**：交付物附一段质检说明——结构选择理由 + 风格贯彻度自查 + 命中项处置记录。没有这段说明 = 没过门

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| A1 | 结构同构 | 与近期产物共享同一骨架节奏 | 列出产物骨架节奏序列（区块顺序+各区块信息密度），与最近 3 个产物对比——序列相同或仅差一个区块 = 命中 |
| A2 | 模板换色 | 只调了色相/字体，组件树复用 | 检查 DOM 结构：class 命名与组件层级与既有产物相同，仅 CSS 变量值变化 = 命中 |
| A3 | 风格贴皮 | 风格只在首屏，滚动后回归默认 | 按选定词条的四要素（特征/字体/色彩/构图）抽查第 3 屏与末尾区块——要素不可辨 = 命中 |
| A4 | 全屏均质 | 所有元素同等重要，无视觉动线 | 眯眼测试：虚焦看页面，若无法在 1 秒内指出「最大最亮」的唯一元素 = 命中 |

### 观察项（记录处置）

| # | 反模式 | 症状 | 判定操作 |
|---|---|---|---|
| B1 | 紫色渐变 hero | 深紫→蓝渐变大横幅+白字居中 | 首屏背景含 linear-gradient 且主色相在 220°-280°（紫蓝域）+ 文字居中 = 命中（词典选定该风格除外） |
| B2 | 居中三卡片 | 三个等宽卡片并排+图标+三行说明 | 存在连续 3 个等宽并排卡片且内部结构相同（图标+标题+行文）= 命中 |
| B3 | 图标堆砌 | 每个标题前硬塞 emoji/图标 | 删除全部图标重读——信息量无损 = 堆砌（有信息增量的功能图标不算） |
| B4 | Inter 全家桶 | 无字体配对意识 | font-family 仅一个家族，且标题与正文字重差 <300 = 命中 |
| B5 | 对称强迫 | 一切居中，无栅格变化 | 主内容区全部 text-align:center 且无任何左右分栏/偏移结构 = 命中 |
| B6 | 假数据感 | 占位文本 | 正文含 lorem / 「示例内容」/「XX 占位」= 命中 |
| B7 | 悬浮物滥用 | 无意义 float 动画 | 存在与内容无语义关联的循环 float/translateY 动画 = 命中 |
| B8 | 色彩超载 | 色相多无主次 | 统计色相数（排除灰阶）：>4 个且最大面积色占比 <50% = 命中 |

## audit 评分输出格式

```
## 泔水分体检报告
结构层：[同构风险/骨架合理] —— 一句依据（引 A1 判定结果）
风格层：[贴皮/贯彻] —— 一句依据（引 A3 判定结果）
观察项：B1 命中（……）、B4 未命中……
致命项：A2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行——修复走 redesign 动词，诊断与执行分离。
