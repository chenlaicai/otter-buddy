# web 反泔水清单与质检门（不过门不出稿）

> 使用时机：design/redesign 产物交付前的最后一道闸。audit 动词以本清单为评分依据。

## 质检门流程（三步强制）

1. **反模式扫描**：下表逐项过，命中任何「致命项」直接返工，命中「观察项」逐条记录处置
2. **自我批评**：以「这产物哪里像 AI 生成的？」自问，至少找出一个弱点并处置（修掉或写明豁免理由）
3. **出门说明**：交付物附一段质检说明——结构选择理由 + 风格贯彻度自查 + 命中项处置记录。没有这段说明 = 没过门

## 反模式清单

### 致命项（命中即返工）

| # | 反模式 | 症状 |
|---|---|---|
| A1 | 结构同构 | 与最近产物共享同一骨架节奏（抹掉颜色后无法区分） |
| A2 | 模板换色 | 只是调了色相/字体，骨架组件完全复用 |
| A3 | 风格贴皮 | 选定风格只出现在首屏，滚两屏后回归「默认 AI 味」 |
| A4 | 全屏均质 | 所有元素同等重要=没有重点，视觉动线缺失 |

### 观察项（记录处置）

| # | 反模式 | 症状 |
|---|---|---|
| B1 | 紫色渐变 hero | 深紫→蓝渐变大横幅+白字居中（AI 出品第一标志） |
| B2 | 居中三卡片 | 三个等宽卡片并排+图标+三行说明 |
| B3 | 图标堆砌 | 每个标题前硬塞 emoji 或线性图标，无信息增量 |
| B4 | Inter 全家桶 | 无字体配对意识，全页一个字体一个字重 |
| B5 | 对称强迫 | 一切居中对齐，无栅格变化，无呼吸节奏 |
| B6 | 假数据感 | 占位文本是 lorem 或「示例内容示例内容」 |
| B7 | 悬浮物滥用 | 无意义 float 动画/视差，与内容无关 |
| B8 | 色彩超载 | 5+ 色相无主次，无色彩系统 |

## audit 评分输出格式

```
## 泔水分体检报告
结构层：[同构风险/骨架合理] —— 一句依据
风格层：[贴皮/贯彻] —— 一句依据
观察项：B1 命中（……）、B4 未命中……
致命项：A2 命中（……）
总评：返工 / 有条件通过（处置清单）/ 通过
```

audit 只诊断不执行——修复走 redesign 动词，诊断与执行分离。
