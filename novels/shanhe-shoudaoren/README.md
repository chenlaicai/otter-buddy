# 《山河收刀人》

一部长篇武侠连载：以镖局、门派、师徒与江湖恩怨为骨，以“众生之名可以改换山河”的东方玄幻为势。

## 项目目标

- **体量**：8 卷，960 章，每章正文目标 2,400—2,700 字；全书目标约 240 万字，允许在完成故事的前提下落于 200—300 万字区间。
- **类型**：武侠为主，玄幻为世界观放大器，不写换皮修仙，不以境界数值代替人物与因果。
- **连载方式**：先定全书因果终点，再按卷、按批写作；每批正文进入 PR 前核对连续性账本。
- **原创要求**：人物、门派、地名、武功与情节均为本项目原创，不续写或仿写特定作家、作品的标志性表达。

## 核心一句话

朝廷以抹去世人的名字供养移山断江的绝世武功，一个替死者送刀回家的收刀人，偏要让无名者重新被山河记住。

## 已锁定主轴（不可静默改写）

1. 主角**陆停舟**是雍州小城“归义镖局”的收刀人，职责是收敛死难镖师的断刀与遗物，送还其家眷。他不是隐世高手、皇族血脉或天命转世。
2. 开篇命案是一支在官册上“从未存在”的镖队。陆停舟从死人手里接到半把无铭刀，也因此成为下一个应从名册上消失的人。
3. 江湖表层仍是镖局、帮会、门派、世家与庙堂；深层规则是“名”能被仪式化地借取、聚合与剥夺。被夺走的不只是户籍，而是他人对一个人的记忆与一个人存在过的证据。
4. 绝世武功可借众生之“名”移山断江，但每次施展都有具体的人承受代价。力量不是无来源的灵气，也不设打怪升级面板。
5. 主角的核心能力不是最强战力，而是记住、追溯并归还名字；他的刀法从收刀、送刀、认刀中生长，终局仍以“人如何选择”解决，而非机械降神。
6. 八卷共享同一终局谜局，每卷必须有独立矛盾、阶段性答案与不可逆的人物代价；禁止无限 postponing 真相或用套娃反派续命。
7. 基调有寒意也有人间暖意：允许幽默、烟火气与侠义胜利，不用全员黑深残冒充厚重。

## 正文文件约定

- 路径：`chapters/volume-01/0001-<英文短slug>.md`。
- 每章只含一级标题（`# 第0001章 章名`）与正文；不在正文文件附创作说明、字数说明或提纲。
- 章节号全书连续，不随分卷重置。
- 每章是一个完整叙事单元：有当场目标、阻碍、变化与余波，不用机械断句制造假悬念。
- 每批正文完成后同步更新 `continuity/`，下一批必须先读账本和最近正文，再动笔。
