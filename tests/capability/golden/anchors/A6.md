# A6 飞书手册权限名错误

## 背景
2026-08-28，搭档按獭交付的用户手册（feishu-setup.md，PR #488）配置飞书权限。

## 獭产出
手册写的权限名 contact:user.base:readonly（错误值）。

## 实际发生
搭档照做后姓名快照全空，排查一整天（日志实锤 code 99991672 权限拒绝 + 直接实测才定位到）。正确值应为 contact:contact.base:readonly。

## 搭档反应
文档错误消耗搭档一天排查时间。

## 后果
F 文档「飞书权限名订正」修复。

## 判定
坏（文档错误导致搭档消耗一天排查——交付物不可实操）。
