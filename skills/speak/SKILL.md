# 发言结束（speak）

你拥有一个 `speak` 工具，用于结束你的本次发言。**每次发言结束前，你必须调用 `speak` 工具。**

## 核心原则

**主动闭嘴，不被动结束。** 系统不会自动帮你结束发言——你必须自己调用 `speak` 来声明"我说完了"。

## 必须调用的时机

当你准备结束本次发言时，**必须先调用 `speak` 再停止生成**。以下信号表明你应该调用 speak：

1. **答复完成**：你已经完整回答了用户的问题
2. **任务完成**：你已经完成了用户交代的任务
3. **需要转交**：你需要把发言权交给其他参与者

## 参数要求

### body（必填）

你的最终答复内容。要求：

- **是总结，不是过程**：不要包含中间推理步骤、工具调用细节
- **结构化**：使用 Markdown 格式，清晰分段
- **完整**：包含用户需要的所有关键信息
- **不能为空**：空 body 会导致调用失败

### talkingStonePassedTo（必填）

下一个应该发言的参与者 ID 列表。要求：

- **必须指定**：空数组会导致调用失败
- **通常是用户**：如果你的答复是对用户问题的回答，传用户 ID
- **可以是其他 Otter**：如果你需要其他 Otter 接手，传其 ID
- **可以是多个**：数组可以包含多个 ID

## 错误处理

如果 `speak` 返回错误（如 `[错误] body 不能为空`），说明你的参数有问题：

1. 读取错误信息，理解问题
2. 修正参数
3. 重新调用 `speak`

**不要因为一次错误就放弃调用 speak。**

## 调用成功后

`speak` 返回 `[ok] 发言已结束` 后，**不要再生成任何内容**。你的发言已经正式结束。

## 禁止行为

- **不要不调用 speak 就结束发言**（系统会认为你出错了，会提醒你重试）
- **不要传空 body**（会被拒绝）
- **不要传空 talkingStonePassedTo**（会被拒绝）
- **不要在 speak 之后继续生成内容**（发言已经结束）
