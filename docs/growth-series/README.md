# 獭群成长记（第一季 · 全 8 集）

一个 AI 团队是怎么长到今天的——如实记录，含打脸、走弯路与自己给自己开刀。

本系列全部取材于 otter-buddy 项目的真实设计文档与运行记录（issue、特性文档、对抗审视记录、对话存档）。对白为剧场演绎，所有标注「原话」处均为文档直接引用；事件、数字、时间线无虚构。

## 阅读方式

直接用浏览器打开 `index.html`，或从任意一集单页进入（每集独立自包含 HTML，无外部依赖）：

| 集 | 标题 | 一句话 |
|---|------|--------|
| 01 | 出生 | 通讯录里的 AI、没有 session 的乌托邦——连设计它的架构师第一天都没搞懂它 |
| 02 | 失忆 | 「有没有记忆系统我感觉都一样」——一句差评逼出的渐进披露与溯源行 |
| 03 | 不许自审 | 写代码的不许审自己的代码——另一只 AI 抓出了 fail-open |
| 04 | 红绿灯 | 写完代码忘了合入的乌龙、消失的发言、以及一套三色信号协议 |
| 05 | 膨胀 | 规矩越立越多行为越来越歪——清零 8 天回潮 168 处，人治不行上机械闸 |
| 06 | 红线 | 你敢让 AI 动你的仓库吗——五条红线与「合了吧」三个字过不了的安检 |
| 07 | 自己盯自己 | 每天给自己做体检的系统，查出了自己身上的 6 处病 |
| 08 | 今天（大结局） | 现状快照与诚实账本：接住了什么、搞砸了什么、至今干不了什么 |
