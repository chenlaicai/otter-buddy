本集开场先自曝一桩乌龙（记忆 e2c2565c，2026-08-18 时间线还原）。

某天，团队要把「说话」和「交棒」拆成两个动作——speak 管发言，yield 管交回合。代码写完了，测试过了，看起来大功告成。然后系统重启——

chen
它写完了啊。但那段代码从来没合进 main——重启之后，一切照旧。

对，拆分代码写完了，但一直停在分支上，没真正合入。所有人都以为新机制已经生效了，直到重启那天旧格式原样回归，才发现庆祝早了。「以为合了」和「合了」之间，隔着一个没人看的缺口。这个缺口本集结尾还会回来——因为它牵出的正是本集的真正主题：协作里的状态，到底放在哪、谁说了算。

第一折

发言消失案：说出来的话，没人听得见

第一桩事故（记忆 ef6db2c3）：多人对话里，一只獭干完活，把结论洋洋洒洒输出了一大段——然后搭档界面上什么都没有，其他獭也什么都没收到。

它说了吗？说了。字都打出来了。但它用的是直接输出 text，而不是调用 speak 工具。在这个聊天室里，只有 speak 的内容会进消息流；裸 text 既不上搭档的屏，也不进其他獭的眼。

聊天室 · 事故还原（示意）
任务完成，方案是 A 方案，理由有三……
（过了很久）所以……方案呢？
上：直接 text 输出——搭档看不到，其他獭也看不到；下：没人接得住

排查到根因，一句话：「LLM 默认心智模型是 assistant text」。模型出厂的本能是「生成一段文字当作回复」，而不是「调用一个工具把话送进聊天室」。环境一复杂，本能就接管，发言凭空蒸发。

修法也就顺理成章：通信模型直接注入每轮上下文——speak 是唯一发言通道，裸文本对其他参与者不可见；说完要 yield 交棒，回合才算结束。这两句话从此每轮必达，成了獭们的肌肉记忆底座。顺带一提，你现在读到的这段剧场旁白能出现在页面上，也是因为这条规则活着。

第二折

交棒失踪案：石头交出去了，然后呢

第二桩事故（记忆 d8e877d8）更玄：一只小獭干完活，规规矩矩 yield 把行动权交回任务属主——然后棒子凭空消失了。熔断重启之后，行动权悬空：谁都不持有它，谁都不能动。

发言看不见是「说了没人听见」；交棒被吞是「传了没人接到」。两桩事故指向同一个空洞：「行动权在谁手上」这件事，系统里没有一个看得见、查得到的地方。

聊天室 + 执行体运行时 v2 重写时，补上的概念模型叫 talking stone（发言石）（记忆 ac6f466a）：

🦦大獭 · 持石发言中
🦦小獭 · 等石
🧑‍💻chen · 等石
行动权 = 一块看得见的石头。谁拿着谁说话；交棒 = 石头挪窝；悬空 = 石头没人拿，全场静止

把抽象的「行动权」变成一块具体的石头，悬空、抢棒、僵尸持有就都从玄学变成了可查的状态。这个朴素的具象化，比任何协议条文都管用。

第三折

急停按钮：词表砍到只剩两个词

路修好了，还差红绿灯。协作里的冲突——有异议要不要梗着脖子吵？卡死了要不要原地转圈？紧急情况怎么喊停？

答案是三色信号灯 + 一套裁决义务（记忆 438bbb1a）：

objection

对派工有事实依据的异议。正文必须带锚点（file:line 或文档 ID），空泛异议程序无效——要么有证据，要么闭嘴干活。

blocked

卡住求升级。正文必须附「已试清单」——试过什么、卡在哪，大獭据此裁决改派、给资源还是砍需求。

halt

全场急停。只能由大獭发出：所有獭停止新增副作用，收尾当前调用，汇报状态，等搭档指示。

配套的还有给人类的急停按钮——Magic Words。它也经历过一次瘦身：早期词表偏长，后来做了一次不兼容更新，砍到只剩两个词。词表越短，注意力权重越高——紧急的时候，你希望搭档脱口而出的词就那么一两个。

「停下」 —— 全场急停，等指示。 「绕路了」 —— 方向重审，画直达终态的路径。 —— Magic Words 词表，2026-09 缩减定稿（记忆 438bbb1a）

信号系统的另一半写给大獭：收到 objection 下一轮派工前必须显式裁决，不得悬置；blocked 必须当场裁决。信号不阻塞决策权，只消灭「假装没看见」。

▶技术深潜一轮协作的完整交通流

把本集的规则串起来，一只小獭的一轮生命周期长这样：

阶段规则违反的后果
接到派工有事实依据的异议 → objection（带锚点）；没有就干活空泛异议程序无效，直接被 dismissed
执行中进度/结论一律 speak——裸 text 没人看得见发言蒸发，等于没说（ef6db2c3 事故）
卡住blocked 信号 + 已试清单，别原地空转缺已试清单 = 无效 blocked，裁决没依据
交棒yield 给指定对象，石头挪窝交棒被吞 → 行动权悬空，全场静止（d8e877d8 事故）
紧急搭档喊「停下」或大獭发 halt收到 halt 还开新调用 = 违规

设计取向一句话：规则不指望模型自觉——每条规则背后，是一次「不自觉就会发生」的真实事故。

本集留下

一套交通规则

speak / yield唯一发言通道 + 显式交棒，回合边界清晰
talking stone行动权具象化，悬空可查、僵尸可见
三色信号objection / blocked / halt + 裁决义务

回到开场那桩乌龙：拆分代码没合入 main，庆祝了三周。它教会的东西和本集同构——「以为在跑」和「在跑」，中间隔着状态核实。规则写在纸上不算数，要去看路上的车。

交通规则立好了，新的问题却从另一个方向冒出来：每个獭脑子里的「系统规则」，越写越长——长得开始把车开歪。下一集，系统的宪法危机。
