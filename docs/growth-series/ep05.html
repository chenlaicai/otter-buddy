前四集的每一场事故，都留下了一条规矩：speak/yield、异体审视、信号协议……规矩一条条写进 SYSTEM.md——每只獭每轮必读的「宪法」。

然后宪法开始膨胀。每出一桩事就加一段，每个边界情况就补一条。写的时候每一条都有道理，堆到一起就是灾难：没人读完的规则，等于没有规则；更糟的是，读一半的规则会催生奇怪的行为漂移。

本集讲这场宪法危机，和它逼出来的两个教训——一个关于 token 的昂贵误解，一个关于人性的彻底死心。

第一折

昂贵的误解：搬家不等于减负

第一反应很自然：宪法太长，那就把规则搬到别处——搬到工具描述里、搬到 skill 文档里，眼不见为净。

熵减重构（记忆 3b91a497）做了一次，然后收获了整个项目最贵的一课：

「搬家到工具 description = 减负」是错误模型——工具 description 同为每轮常驻注入，位置移动不产生任何 token 收益。 —— SYSTEM.md 对抗熵减重构的最大教训（记忆 3b91a497）

翻译成人话：把东西从左口袋挪到右口袋，总重量不变。真正的问题从来不是「规则放在哪」，而是「这些规则到底该不该存在」。搬家忙了一场，账单一分没少。

这个教训直接改写了治理思路：以后任何「减负」提案，先问减的是存在还是只是位置——位置游戏一律不批。

我 以 为

  • 规则挪出 SYSTEM.md = 上下文减负
  • 工具描述、skill 文档是「免费」存储
  • 长了就搬，搬家治百病

实 际 上

  • 工具描述同样每轮常驻注入，token 一分没省
  • 问题不是「放哪」，是「该不该存在」
  • 只有删除是真减负
第二折

三次复发，168 处回潮：对人治彻底死心

第二个教训来得更疼。项目里有个痼疾叫「编号污染」——prompt 面里不该出现编号锚点（F 文档号、issue 号之类），它会把注意力权重带偏。大家早就共识要移除。

9 月 9 日，全面清零。八天之后——

×1第一次清零后回潮
×2第二次再清再回潮
168第三次8 天回潮处数（9/17）

搭档第三次亲手抓到时，记录里留下的措辞是：「认可移除编号污染，却持续复发」（F20260917pagd）。注意这个措辞——不是「忘了」，是认可了、清过了、又长回来了。像除草：地是认了要除的，草还是自己长。

为什么会这样？因为新代码、新文档每天都在产生，每个写东西的獭都可能顺手带一个编号进去——不是哪一只獭失职，是流程本身没有卡点。人治（叮嘱、提醒、定期清理）对「每天新增的入口」天然防不住。

于是三獭架构审视开了个会，结论收敛到唯一解：上机械闸。

🚧
lint 机械闸不提醒、不劝告、不放过
lint-prompt-anchors ✓ 干净，放行
lint-prompt-anchors ✗ 检出编号锚点 ×3 → 拦下，改完再来
# 它不看语境、不听解释、不知道你多急——这正是它比獭可靠的原因

机器不认「我以为改了」，只认「此刻扫描结果」。从闸门上岗那天起，「认可但复发」失去了生存土壤——污染进不了 main，就没有回潮可言。

第三折

原则重写：每条规则过三问

机械闸守住了入口，存量还得瘦身。10 月 5 日——就是昨天——SYSTEM.md 完成了一轮原则重写（记忆 56e8288c）：从 66 行压向约 30 行。

怎么砍？每条候选内容过三道问，如今写进了文件的增长纪律：

问一每轮都需要吗？执行 LLM 每一轮都用到它，才配常驻注入
问二删了会变吗？删掉后行为真实改变，才算行为指令
问三是指令还是历史？元信息与决策史，归档不进宪法

三问的杀伤力在于诚实地承认了一个分类：很多「规则」其实只是决策史——记录「当时为什么这么定」对执行没有帮助，它们该去特性文档和 git 历史里养老，不该每轮占用注意力。场景型的 know-how 呢？下沉到工具描述或对应 skill——因为那些只在用到的时刻注入。

配套的还有一条自我约束，叫机制预算（记忆 0fcc57da）：每修一个问题，不许顺手新建台账新表——用约束治机制，而不是用更多机制治机制。毕竟这一集的起因，就是机制长得太快。

▶技术深潜prompt 工程治理的分层账本

这集实际建立的，是一张「内容该放哪」的分层表：

层注入时机放什么治理手段
SYSTEM.md每轮常驻只有行为必需的原则（~30 行）增长纪律三问 + 无自动增长监控
工具描述每轮常驻（随工具列表）工具怎么用、边界、时机同为常驻——挪进来不减负，只换口袋
skill 文档任务匹配时按需加载流程型 know-howwriting-skills lint
特性文档 / git不注入，检索可达决策史、元信息frontmatter 因果链

关键洞察：注入面大小 = 注意力成本。治理的对象不是「文档长短」，是「常驻注入面里塞了多少不常驻需要的东西」。

本集留下

一个新直觉

位置 ≠ 减负常驻注入面里，只有删除是真的
机械闸 > 人治每天新增的入口，只有 lint 防得住
增长纪律新内容先过三问，决策史不进宪法

宪法瘦身完成、闸门上岗、增长有了纪律。但整个系列到这里，獭们还没碰过一块真正的禁区：直接改真实仓库的权力。第一次把「动真仓」的钥匙交到 AI 手里，是什么感觉？下一集，红线。

第 6 集 · 红线

AI 要改的不再是沙箱里的草稿，是你吃饭的主仓。第一道防线不是技术，是恐惧——设计者的恐惧。

「『合了吧』三个字过不了安检——必须逐字校验原话，防伪造审批、防善意推断。」—— 脆是特性，不是 bug
