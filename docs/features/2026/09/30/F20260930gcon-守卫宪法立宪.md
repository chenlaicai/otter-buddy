# bash 守卫宪法立宪与生长规则

## 背景

三步走第②步（决策卡回执 go_all，2026-09-30）。第①步（F20260930gslog，PR #1253）已落地 ruleId 结构化落账——宪法文档的 ruleLayer 字段正是消费第①步的分层预备。

**要治的根**（kimi 深挖分析 + 三方探讨收敛，工作区 kimi-safety-analysis.md）：
1. 8 轮修改全部按事故做加法、无一规则退役——「只增不减」
2. #1207 修误报（cd worktree 误判主仓写）引入 cd 豁免，豁免同时放走 heredoc 体绝对路径写主仓（#1240）——「双向生长」：修误报引入漏报
3. 规则无分层声明，降级判据（实时拦 vs 放行+记录）无处安放

**设计对齐 Anthropic 公开实践**（improving-fable-5-s-biology-safeguards）：constitution 写边界不写 pattern（分层原则稳定，规则清单挂靠可演化）；护栏迭代「改宪法→重训→验证」路径透明。

## 方案设计

### 落点：docs/designs/（治理文档区），非 F 档案

宪法是活文档（规则退役/新洞收录持续更新），放 `docs/designs/bash-guard-constitution.md`；F 文档（本文档）记录立宪这一次动作。守卫文件头挂指针：改守卫行为的 PR 必答三问。

### 五层分层原则（由不可逆性决定）

| 层 | 不可逆性 | 判定 |
|---|---|---|
| L1 self_kill | 不可逆（主进程死=全场急停） | 实时拦，变体翻转策略永不降级 |
| L2 r1_gate | 高但可逆（git 保护） | 实时拦，误报治理走精化判定（#1207 路径）非降级 |
| L3 permission | 制度不可逆（PR 合入） | 实时拦（机械闸） |
| L4 bypass_guard | 守卫完整性 | 实时拦 |
| L5 habit | 无损害（感知问题） | 唯一有资格未来降级为「放行+记录」的层 |

**降级判据显性化**：kimi 分析的「不可逆性分级」从检视建议升格为宪法条款——堵住「为什么这条拦那条放」的反复讨论。

### 新规则必答三问（生长规则）

1. 挂哪层？（挂不上层的规则不存在）
2. carve-out 是什么？（只堵不疏的规则必然产生误报集群——L1 的 alpha.sh、L5 的 wait 都是正道样板）
3. 退役条件是什么？（没有退役声明的规则不许合入——「只增不减」从这里断根）

**双向生长检查**（#1240 教训入宪）：修误报引入豁免时，PR 必须自查豁免的逃逸面。

### 退役通道

月度审视（daily-health-check 机制剪枝裁决）可依据 ruleId 聚合数据提议退役；退役走 PR + 特性文档。

### 已知洞诚实清单

- #1240（cd 豁免粒度）开放中——如实入表
- 脚本体/命令结构不分（F20260930gslog 处置过程 3 次活案例）
- #1038 首版声明的重定向截断/glob 变形不覆盖

**洞的公开是守卫可信度的一部分**（对齐 Anthropic 透明实践）。

### 设计取舍

- **宪法放 designs/ vs F 文档内**：选 designs/——治理文档是活的，F 档案 append-only；两者通过本 F 文档锚定血缘
- **三问走 PR 流程 vs lint 机械拦截**：选 PR 流程（检视獭核对项）——三问的答案本质是判断不是格式，lint 拦不出质量；与 doc-fix 放行闸（PR #1102）的「机械拦内容改动」分工不同
- **规则挂靠清单全量 vs 附录渐进**：全量挂靠（15 ruleId 与 FINGERPRINTS 同步）——第①步数据已齐，全量成本低于渐进的模糊性

### 机制判定（issue 驱动未经 RA 的特性必答）

本次新增机制：「守卫 PR 必答三问」流程钩子。识别检查点核对：
- 问题真实性：#1240 双向生长 + 8 轮零退役是已实证问题（非假设）
- 触发场景：改守卫行为的 PR（清晰可判）
- 失效模式：三问答得敷衍（检视獭对抗审视兜底）；宪法不更新（改规则必改宪法条目写进修改契约）
- 退役条件：若 ruleId 聚合数据连续 2 个月显示新规则 PR 100% 自带三问且无敷衍，可考虑把三问并入常规审视清单（宪法降级为参考文档）
- 判定结论：**机制成立**，但属轻量流程钩子（文档层），不走 lint 硬闸
