# 獭之传说·海藻农场 P0 灰盒

## 背景

方案 F20261009oqtd v2（回合制→农场模拟方向重构）经搭档 2026-10-10 拍板「ok」批准并合入（PR #1387 squash `20ed6570`）。本 PR 落地其 P0 分期：**开局第一幕 + 点位 1（播种）完整三段式 + 渐进解锁框架**——验证两件事：三段式教学循环的手感、灰态解锁的引导性。

## 交付物

| 文件 | 内容 |
|------|------|
| `game/index.html` | 单文件静态页（HTML+CSS+JS 零依赖，file:// 可开）：顶栏（跳过出口）+ 前 90 秒承接横幅 + 9 点位农场网格 + 演出区（三段式舞台）+ 幼獭状态卡（成长可视化） |
| `eslint.config.mjs` | ignores 增 `game/**`（方案§6 实施前置 ①，防 CI lint 红游戏码） |

## P0 内容结构

**第一幕 · 一无所有**（开场）：「一只幼獭漂到了这片荒芜的海藻农场」→ 点开始后仅 🌱 荒田发光，其余 8 点位（含镜湖终战）灰态剪影可见——自由感预告 + 引导唯一性。

**点位 1 · 播种 三段式**：
- ① 问题任务：「幼獭不记得昨天——翻遍农场找不到工具，每次醒来都是全新的一天」
- ② 引入能力：挖坑种下「今天发生的事」盖上土（发芽动画 0.7s，操作推进无等待）
- ③ 效果达成：记忆作物 🌾 挂上背包（pop 动画）+ 幼獭文案变化（「一无所有」→「记得今天」）+ 映射点破卡：「播种 = 记忆入库：发生过的事写下来，不再丢失。每条记忆都有出处、可回溯」

**P0 收尾**：完成卡 + 方案排期提示 + repo 引导（温和，不弹窗不打断）。

## 渐进解锁框架

- 数据模型 `SPOTS[]`：8 教学点位 + 镜湖终战，各含 icon/name/能力映射/p0 标记
- 状态机 `S.phase`：idle → problem → act → effect → done
- 渲染规则：`locked`（灰态剪影）/ `active`（发光脉冲动画，唯一可点）/ `done`（✓ 可回看）
- P1 扩展方式：SPOTS 内点位补三段式剧本函数即可，框架不动

## 验证

- **Playwright 程序化走查**（worktree 内临时脚本，跑完即删不入 commit）：开局→点位1→三段式逐段点击，断言 bag=`🌾`、幼獭文案、阶段标签、映射卡渲染、点击间隔 <500ms（3s 约束的余量证明，间隔含脚本调度开销）——**SELFTEST PASS**
- file:// 打开无网络依赖（零 CDN、零字体外链）——方案验收第 8 条的前置
- CI 面：eslint ignores 已覆盖，lint 无新增告警

## 视觉迭代记录（搭档三轮反馈）

| 版 | 形态 | 搭档反馈 |
|----|------|---------|
| v1 | HTML 卡片 + 文本演出 | 「我很不喜欢这种文本式的。你直接做成像素游戏的，然后有画面那种」 |
| v2 | Canvas 320×180 粗像素 | 「类似于星露谷那种像素，现在粗/复古简陋」 |
| v3 | Canvas 480×270 精绘（16×16 tile 三层着色） | 「海獭有点像个球、这一点先修复下；整个场景也有点简陋，不够慢慢优化」→ 形体改斜侧姿态 + 场景加密（围栏/灌木/野花/石头/远景海藻） |

v3 精绘规格：草地 tile 8 变体噪点+草叶簇、耕地垄沟+土粒高光、水面 3 帧波光+月倒影、角色四层着色（轮廓/深背/浅背/腹高光）两帧游动、木箱板缝钉子顶沿、瓢虫屋鳞片瓦三层+暖窗灯光晕、玻璃罩斜高光+石沿、夜色四段渐变+闪烁星+月晕+萤火虫。

检视獭1422b delta 审视（0 严重 5 建议）处置：
- 发现 1（调色板 15 键悬空致围栏/野花/海藻静默渲染为背景色）→ 已修：补全 15 键，Playwright 实测 fence 色 RGB(58,42,22) 实际渲染，总色数 307→316
- 发现 2（发光环比热区宽 12px，环右缘点击无响应）→ 已修：热区扩至与发光环一致（x-8..x+56），实测边缘坐标 (85,200) 命中
- 发现 4（文档未记录视觉迭代）→ 本节即是
- 发现 3（每帧 11.7k 次 fillRect 无烘焙，实测 61fps 不掉帧）+ 发现 5（SPOTS tw/th 元数据未被消费）→ P1 处理（性能余量充足；tw/th 届时随 8 点位剧本统一对齐）

## 影响范围

- 主系统 `src/` `web/`：零触碰（纯新增 game/ + eslint 一行）
- CI：lint 行为一行变（game/** 不再被扫）
- 部署：P3 才接 Pages（届时需搭档设置 Settings→Pages Source=GitHub Actions）

## 设计取舍

| 取舍 | 决策 | 理由 |
|------|------|------|
| 单文件 vs 模块化 | 单文件 index.html | P0 灰盒验证手感，不预设结构；P1 点位全量时再拆（届时文件结构决策随内容量定） |
| 点位 2-8 的 P0 形态 | 灰态剪影 + hover 无响应 | 验证「可见但不可达」的引导性——方案要求灰态可见保留自由感预告 |
| 幼獭成长可视化粒度 | 文案 + 背包 emoji + 头像微放大 | 零美术资源约束下的最大表达；P3 视觉包装再升级 |
| 自检脚本去留 | 临时文件跑完即删 | 走查脚本依赖对话工作区 playwright，非项目依赖；P1 全量时若固化走查再随 CI 定 |
