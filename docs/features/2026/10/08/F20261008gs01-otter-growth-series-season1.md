# 獭群成长记第一季

## 背景

搭档计划在公司内部技术社区发帖介绍 otter-buddy，经两轮方向校准后定调（搭档原话意图）：

1. 「ai agent 发展到今天，能力展示向内容非常普通」——不写能力炫耀
2. 「要如实地写，既有故事的发展型（我一开始的期望），也有技术的成长和迭代」
3. 「放到一篇里够呛，设计一个七八集的小剧场」
4. 「不能光文字，要生动有趣的展示形式」
5. 「放到 github 仓库上，读者可以自行来当故事看」← 本 PR 落地此条

## 内容

`docs/growth-series/` 下 10 个文件：index.html（全季目录）+ README.md（导引与素材溯源说明）+ ep01-08.html（8 集正片，每集自包含无外部依赖，1500-2100 字正文）。

每集统一叙事公式：当时的期望/痛点 → 现实打脸 → 技术被逼着迭代 → 留下了什么。

| 集 | 对应系统演进 |
|---|------------|
| 01 出生 | issue #3 设计哲学、Chat as Interface→Substrate 纠偏、UA-8/9、speak 诞生（fixme 时代）、身份认知体系 |
| 02 失忆 | 渐进披露（F20260716szw8）、召回 v2（F20260811mrpy）、三獭对抗讨论、记忆溯源行 |
| 03 不许自审 | 异模型对抗审视协议、PR #1231（fail-open）、PR #1255（README 计数漂移） |
| 04 红绿灯 | speak/yield 乌龙、发言消失案、talking stone、objection/blocked/halt 信号协议 |
| 05 膨胀 | SYSTEM.md 熵减、锚点污染 168 处回潮、lint 机械闸、牵引力三问 |
| 06 红线 | worktree 隔离、PR-only、merge 授权原话闸 |
| 07 自己盯自己 | healing 台账、每日体检硬门禁（F20260824dhck）、守门人机制退役、飞轮断环自查 |
| 08 今天 | 现状快照、诚实账本、炒股能力完整一生（F20260920stkx 下架如实写）、期望清单对账 |

## 诚实声明执行方式

- 全部事件/数字/原话有档案锚点（素材库 materials.md 逐条登记，含记忆条目 ID / F 文档号 / PR 号）
- 演绎对白以「下面对白为剧场演绎」旁白 + anchor-note 原话注脚标注
- ep06「第一次动真仓」决策讨论无存档，按机制动机抽象写并在页脚注明
- ep08 炒股能力按 2026-09-23 下架事实写（不列为现行能力）
