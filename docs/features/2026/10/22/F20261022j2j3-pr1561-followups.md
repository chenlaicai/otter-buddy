# PR #1561 审视 follow-up：J2 + J3 修复（M-e595e8f2）

## 背景

PR #1561（F20261019f714）合入时审视遗留两条 follow-up（原 review 意见见 #1561 comments）：

- **J2（严重，fail-closed 向真实伤害面）**：`scripts/lint-historical-docs.mjs` `differsOnlyInLinkPaths` 的 stripAll 双正则顺序扫描缺陷——实证 rename+token/link 同步（其余字节全等）被拒（token 先于 link 时骨架污染）。建议：两 RE match 位置统一排序单趟扫。
- **J3（建议，纯诊断输出）**：`src/frameworks/agent/bash-safety-guard.ts` 进程名回显 `(?<!\/)` 只挡绝对路径邻接，`node dist/src/main.js` 相对路径形态仍标「进程名模式」。建议：token 含 `/` 一律不标。

## J2 根因与修复

**根因**：stripAll 先跑 LINK_RE 全趟剥离，再跑 TOKEN_RE 第二趟——第二趟从 token 位置再切时，token 之后的链接区段被重复切片/丢失，骨架被切坏。同一行内 token 先于链接的合法订正行因此骨架比对失败 → 误拒。

最小复现（修复前，`node /tmp/j2-repro.mjs`）：

```
oldL = "见 `F-old.md` 与 [文档](../01/F-old.md) 两处引用"
newL = "见 `F-new.md` 与 [文档](../01/F-new.md) 两处引用"
differsOnlyInLinkPaths(oldL, newL) = false   // 期望 true：合法行被误拒
```

**修复**：`matches(s)` 收集两 RE 的 match 按 `index` 统一排序，stripAll 与 collect 共用同一份位置序单趟扫。顺带消掉原 collect（各 RE 拼接序）与 stripAll（剥离序）顺序不一致的潜在错位——同序后两函数语义天然一致。

fail-closed 保持验证（修复后，同脚本）：正文改写 → false（仍拦）、token 先行的合法 rename 同步 → true（放行）、链接先行的旧形态 → true（回归不变）、伪链接形态 `` `x.md`foo](y) `` → false（不误放）。

## J3 根因与修复

**根因**：`(?<!\/)` 只挡紧邻 `/` 的绝对路径邻接；相对路径形态 `dist/src/main` 的 `d` 前是空格仍命中。

**修复路径记录**：先尝试可变宽 lookbehind `(?<![^\s/]*\/)` 表达「token 含 / 不标」，发现对「同 token 前缀段含 /」的 `a/bdist` 形态不生效（起点紧邻字符非 `/` 即放行）。初记为「V8 可变宽 lookbehind 行为与预期不符」，#1620 对抗审视（检视獭-1620）实测纠错：`(?<![^\s/]*\/)` 与 `(?<!\/)` 在 v24.14.1 六用例完全等价——`[^\s/]*` 字符类本身排除 `/` 跨不过 `/`，数学上只够到紧邻字符，**是正则写错不是 V8 缺陷**；正确写法 `(?<![^\s]*\/[^\s]*)` 可达目标语义。

**落地修复**：执行期 token 判定——进程名正则原样匹配，命中后检查匹配片段或同空白分隔 token 的前缀段（token 起点到匹配起点之间）含 `/` 则跳过不标。语义即审视建议的「token 含 / 一律不标」，且不误伤真实进程名形态。采纳执行期判定而非修正后的 lookbehind，因诊断面粒度允许且更直白可控（检视獭认可「落地方案更好，仅修注释归因」）。仅影响诊断回显，不影响拦截判定（该模式在 locateTriggerContext 只做回显，在案）。

执行期判定对照（修复后行为，测试断言锁定）：

| 命令形态 | 命中回显 | 说明 |
|---|---|---|
| `pkill -f otter-buddy` | 进程名模式 ✓ | 真实进程名，保持 |
| `kill -9 <pid>`（exe=node） | 进程名模式 ✓ | 保持 |
| `/Users/…/otter-buddy/dist/src/main.js --port` | 不标（旧已收窄） | 绝对路径，回归不变 |
| `dist/src/main.js --port 3100 && sleep 5` | 不标（J3 新增） | 相对路径形态，仍被 sleep 规则拦 |
