# 獭之传说·海藻农场（Otter Tales: Kelp Farm）：README 游戏化获客

## 背景

搭档原话（意图锚）：

> 「我有个想法，我想优化下咱们海獭系统 github 的 readme，或者说，我期望有一种更有趣的方式、能够吸引 star。比如说，游戏。在游玩的过程中，又有乐趣，又能了解到海獭系统的各项功能能力。表现咱们海獭系统的功能能力。」（2026-10-09 11:10）

> 「我觉得扮演大獭是一个不错的 idea，但内容形式可以调整下，不要再是工作，比如说 打怪？用技能？你做一些概念映射」（2026-10-09 11:45）

> 「你提到的最终 boss 是『失传的大獭』idea 不错，屠龙者总成恶龙 这种命运循环的宿命感也是很多游戏的剧本。咱们就可以是 不断升级自己，那打败的就是过去不好的自己 这种寓意。」（2026-10-09 11:48）

方向迭代（2026-10-10，本版方向定稿）：

> 「我在期望，更自由一点？种田的那种。类似于一些农场类游戏，种田休闲，但是也能有打怪部分。比如说，可以把海獭系统的记忆系统、上下文管理、协作等方式，都找到对应的一种『种田』行为，然后有输入有反馈、这个过程趣味地让用户了解咱们系统有哪些能力、能力是什么效果。」（10:09）

> 「1.我觉得，咱们不能拉长时间，这是咱们跟游戏的核心区别，咱们的使用场景不能耗时、不能等待。顶多 3s。2.可（灰盒范围）。3.按种田来……我感觉不需要有海胆，反而变复杂了。」（10:25）

> 「1.点位可以逐渐增加来做。2.每一个点位也要像海獭系统的各个能力一样，是有一个问题、然后引入这个点位能力、然后达成了什么效果。这个问题也要映射为一种问题任务。你开工来写。」（10:25）

首版回合制方案经镜獭 7 条建议审视处置后定稿（载体/eslint/Pages/前 90 秒承接等结论由本版继承），终章灰盒（镜湖 v1-v3）已在对话内完成节奏验证与死锁修复。本版为方向重构：回合制 4 章主线退役，农场模拟上位，镜湖终战保留移植。

## 目标

- T1: README 访客点击即玩（零安装、GitHub Pages 静态站），3 分钟内完成「开局→农场成长→终战→剧终」完整体验
- T2: 8 项系统能力（记忆入库/检索/上下文管理/前世封存/自愈/协作/异体审视/worktree+PR 红线）以「问题任务→引入能力→效果达成」三段式完成教学，玩家通关后能用自己的话说出每项能力解决什么问题
- T3: 3 秒反馈约束——任何玩家操作在 3s 内必有可见反馈（动画/文字/状态变化），全程无「请稍候」、无体力等待、无真实时间流逝
- T4: 终章镜湖 BOSS 战形成情绪高潮与传播点（「你击败了 Lv.1 的自己」+ They have names. 落版）
- T5: 灰盒先行——先验证「1 个点位完整教学循环 + 渐进解锁框架」的手感，再铺全量

## 非目标

- **不做海胆灾害系统**（搭档 2026-10-10 明确否决：「反而变复杂了」）——虫害仅作瓢虫屋点位的教学素材，不构成全局灾害机制
- **不做真实时间流逝**（3s 约束排除：种下作物不等 N 分钟才发芽——生长由操作推进）
- **不做账号/存档/多结局**——单次会话完整体验，刷新即重开（README 传播场景不需要留存）
- **不做多语言**——首版中文（README.en.md 链接入口保留，游戏内文案后续按需补英文）
- **不接入主系统运行时**——game/ 为纯静态站点，不依赖 src/（与首版结论一致）

## 方案设计

### 1. 三幕结构

**第一幕 · 一无所有**（开局 ≤15s）：一只幼獭漂到荒芜的海藻农场——田是灰的、背包是空的、身边没有队友。引导文案极简：「点点什么，让这里活起来。」初始可点击点位仅 1 个（🌱 荒田），其余点位以剪影/灰图钉形式可见但不可点（渐进解锁的可见性预告）。

**第二幕 · 农场即课堂**（主体，约 2 分钟）：8 个点位逐个解锁，每个点位 = 一项系统能力的三段式教学（问题→能力→效果）。解锁顺序即教学梯度：先解决「记不住」（记忆），再解决「记太多」（上下文），再引入「帮手」（协作），最后引入「规矩」（审视与红线）。

**第三幕 · 镜湖终战**（约 45s）：农场能力全部入账后，湖面解锁。旧灰盒五段式整体移植，终战每个动作的台词回指农场教学来源（详见 §4）。

### 2. 点位设计（问题驱动三段式）

每个点位遵循固定剧本结构：**① 问题任务**（游戏内具象化的痛点，与真实系统痛点同构）→ **② 引入能力**（点位交互教学，1-3 次点击）→ **③ 效果达成**（可见收益 + 能力入账动画 + 一句话点破映射：「这对应系统的 XXX」）。

| # | 点位 | 映射能力 | ① 问题任务（游戏内） | ② 交互 | ③ 效果达成 |
|---|------|---------|---------------------|--------|-----------|
| 1 | 🌱 荒田播种 | 记忆入库（create memory） | 幼獭不记得昨天：屏幕闪回「昨天的你把工具放哪了？」→ 翻遍农场找不到 | 点播种 → 种下一颗「今天发生的事」 | 作物发芽挂上背包（≤1s）+「记忆入库：发生过的事不再丢失」 |
| 2 | 📖 种子库 | 记忆检索（search_memory） | 同一个问题又要重新种一遍：提示「这个坑上周踩过？」——但想不起来细节 | 翻种子库 → 命中旧种子 | 旧种子直接发芽免重种（3s 内）+「记忆检索：旧结论直接复用」 |
| 3 | 🚿 板结田施肥 | 上下文管理（摘要/压缩） | 田越种越多，幼獭动作变慢：走路延迟、说话卡顿（上下文膨胀的可视化） | 点施肥翻耕 | 速度恢复 +「上下文管理：太重的记忆自动摘要，行动不减速」 |
| 4 | ♻️ 休耕田 | 前世封存/交接（restart） | 一块田连种百季产量骤降，怎么浇都不长（长会话退化） | 让田休耕一季 | 残茬变堆肥，「+50%」飘字演出（数值仅为一次性演出反馈，不进入持久状态——单次会话无跨季数值系统） +「前世封存：一段经历浓缩成养分交给下一世」 |
| 5 | 🐞 瓢虫屋 | healing 自愈 | 每次收获后蚜虫总要来偷袭一轮，幼獭不可能时刻盯着农场 | 建瓢虫屋 | 瓢虫自动出动吃蚜虫 + 巡田记录本多一条 +「自愈：小问题系统自己修，记录可查」 |
| 6 | 🦦 邻居小獭 | 召唤协作（create_otter/编排） | 收获季农活堆积如山，一只獭干不完 | 敲邻居门招募 | 各展所长分工加速；小獭会累（429 哑火）需轮换 +「多獭协作：专长分工，体力=配额」 |
| 7 | 👴 老农验田 | 异体审视（adversarial review） | 幼獭检查自己的田三遍都说没虫——直到老农来了一眼指出叶背的卵 | 请老农 | 虫害显形标记 +「异体审视：自己的产出自己看不出问题，换一双眼睛」 |
| 8 | 🧪 试验田 | worktree + PR + 授权原话 | 新品种直接种主田，病害传染砸了一季收成 | 试验田隔离试种 | 收成后需玩家在输入框打出「合入」二字才进主田粮仓 +「改动隔离：验证过、你亲口批准，才进主干」 |

**渐进解锁规则**：任一时刻农场可见全部 8 个点位（灰态剪影），但仅「当前教学点位」+「已完成点位（可重复交互）」可点。完成当前点位后下一个点亮（点亮瞬间有引导动画指向）。玩家在已完成点位重复操作有轻量反馈（如旧作物摇一摇），不阻塞主线。终战入口（镜湖）在第 8 点位完成后出现。

**教学梯度的设计意图**：1-2 教「为什么需要记忆」；3-4 教「记忆需要管理」；5 教「系统自愈」；6 教「协作」；7 教「审视」；8 教「红线」——与真实用户对 agent 系统的认知升级路径同构（先用→用好→管好）。

### 3. 三秒约束的实现

- **操作推进制**：作物生长阶段（播种→发芽→抽条→成熟）由点击推进，每阶段转换动画 ≤1s；无任何「等待 N 秒」的模拟时间
- **反馈即时性**：每次点击的反馈 = 动画（发芽/瓢虫起飞/小獭挥手）+ 文字（一句话映射点破）+ 状态变化（背包/农场外观），三者同帧出现
- **演出性延迟上限**：问题任务的「延迟可视化」演出（点位 3 走路卡顿/说话变慢、点位 6 小獭哑火沉默）单次 ≤1s 且可点击跳过——问题任务恰是 3s 红线最容易被自己的教学演出违反的地方，与终战迟滞演出（250ms/500ms 级）统一口径
- **终战节奏继承灰盒验证**：镜湖 v1-v3 灰盒已实测五段式每步反馈 <3s（BOSS 的「上下文迟滞」演出用 250ms/500ms 级延迟模拟卡顿感，属演出而非等待）

### 4. 终章 · 镜湖（移植自已验证灰盒）

五段式结构保留（灰盒 v3 已验证节奏 + 死锁修复），能力来源回指农场：

| 终战动作 | 农场来源（教学回指） | 原映射（保留） |
|---------|---------------------|---------------|
| 🔮 占卜 | 种子库（点位 2）| search_memory |
| ✨ 召唤洞察獭 | 邻居小獭（点位 6），含哑火→换獭机制（v3 修复：新獭首刀必中）| create_otter + 首哑处置 |
| 🛡️ 结界 | 试验田（点位 8）——「试验田里你已经隔离过一次」 | worktree 隔离 |
| 🔍 审视 | 老农验田（点位 7）| 异体执行 |
| 🔏 封印咒语「合入」 | 试验田（点位 8 玩家已打过一次这个字）| merge_pr 授权原话 |

BOSS「过去的大獭」设定不变：拒绝记忆（图鉴空白）、拒绝队友（孤身）、上下文爆炸（自言自语越来越慢）。击败后「你击败了 Lv.1 的自己」+ 幼獭剪影长大、身后站满召唤过的队友 + 「They have names.」落版 + repo 链接。

叙事回指闭环：终战每个动作的台词逐一回指农场教学来源（占卜=种子库翻出的旧种子、召唤=邻居小獭教过的轮换、结界=试验田的隔离、审视=老农教的洞察、封印咒语=试验田里玩家已亲手打过的「合入」）。渐进解锁保证玩家到终战必然已学完全部能力，线性路径下闭环天然成立，无需拦截门——回指的价值在叙事层强化「你在农场学的每个能力都在终战用上了」，通关即证明全部能力已体验。

## 影响范围

- 主系统 `src/` `web/`：**零影响**（game/ 独立静态站，无运行时依赖；同首版结论）
- CI：`eslint.config.mjs` ignores 一行变更（game/** 加入忽略）
- README.md / README.en.md：首屏插入游戏区块（P3）
- 对话内已验证资产：镜湖灰盒 v3（本对话工作区 quest-rpg/game.html）为 P2 移植源

## 风险与约束

- **3s 约束是产品红线**（搭档 2026-10-10）：任何真实等待 >3s 即违背「与系统的核心区别」定位——P0 验收必测项
- **问题任务的说教风险**：问题→能力的三段式若文案太长会变成「带按钮的文档」——每段文案 ≤2 行，问题用场景不用解释
- **8 点位时长失控风险**：教学点位多，若单点位超 20s 总时长破 3 分钟承诺——P1 用「每点位点击数 ≤5」硬约束
- Pages 启用依赖搭档操作（不可自动化），列 P0 前置项

## 设计取舍

| 取舍 | 决策 | 替代方案 | 理由 |
|------|------|---------|------|
| 游戏形态 | 农场模拟（自由点击点位制） | 回合制 RPG（首版方案） | 搭档 2026-10-10 定向：种田的自由感 + 「有输入有反馈」的短循环更贴系统真实体验；回合制的强引导感与「3s 无等待」约束冲突 |
| 灾害系统 | 无海胆，虫害仅为瓢虫屋教学素材 | 海胆潮灾害事件 | 搭档否决：「反而变复杂了」；灾害稀释「每点位=能力教学」纯度 |
| 时间机制 | 操作推进制（无真实时间） | 动森式真实时间 / 星露谷式压缩昼夜 | 3s 约束（搭档拍板）直接排除两类真实时间方案；操作推进与「系统秒级响应」同构 |
| 教学结构 | 问题驱动三段式（问题→能力→效果） | 功能导览式（直接展示能力） | 搭档 2026-10-10 要求：「是有一个问题、然后引入这个点位能力、然后达成了什么效果。这个问题也要映射为一种问题任务」——先痛后药的记忆强于先药后症 |
| 点位解锁 | 渐进解锁（灰态可见） | 全开放自由探索 | 搭档：「点位可以逐渐增加来做」；教学梯度需要顺序（先用→用好→管好）；灰态可见保留自由感预告 |
| 终战承接 | 镜湖五段式整体移植 + 农场回指 | 重写终战 | 灰盒 v1-v3 已完成节奏验证+死锁修复（沉没成本已付清）；教学-考核闭环（终战动作=农场能力）强化「通关即理解」 |
| 美术资源 | emoji+CSS 动画，零图片资产 | 立绘/像素资产 | 首版结论继承：先跑通体验，视觉包装 P3 增强（避免美术成为阻塞项） |
| 机制识别检查点 | 不涉及净新增机制 | — | 本方案为 game/ 静态内容产品：无新增配置/状态生命周期/定时任务/信号/持久化/决策分支/跨模块调用，主系统零触碰 |

**方向变更决策记录**：首版回合制方案（4 章+终章）经镜獭审视处置定稿后，搭档试玩终章灰盒提出农场方向——首版的教学结构（战斗机制映射）与终章资产（镜湖五段式）保留继承，章节主线（黑雾森林/分身荒原/捷径回廊）退役。镜獭 7 条建议中，载体/eslint/Pages/前 90 秒承接/终章灰盒先行 5 条继续适用，映射准确性原则（本版以「问题任务同构」重新落实）、3 分钟通关承诺继续有效。

## 验证

人工验收清单（部署后逐项过）：

1. **3s 反馈抽测**：随机点 20 次交互，每次从点击到可见反馈计时 ≤3s（录屏核对）
2. **三段式教学完整性**：8 点位逐个走查，「问题任务出现 → 能力引入 → 效果达成」三段齐全且文案各 ≤2 行
3. **渐进解锁**：跳过引导的裸玩家（无任何提示）能否自然发现「当前只有一个点位可点」；已完成点位重复交互不阻塞
4. **终战回指走查**：终战五段式每个动作的台词是否点名农场来源（占卜→种子库/召唤→邻居小獭/结界→试验田/审视→老农/封印→试验田咒语）；全部完成后通关
5. **通关时长**：熟练路线 ≤3 分钟；首次游玩 ≤5 分钟（教学阅读时间计入）
6. **README 链路**：从 README 点击到游戏加载 ≤5s（Pages 冷启动）；「跳过游戏」出口可达 README 对应锚点
7. **镜湖回归**：v3 修复（哑火换獭+首刀必中）在移植版复测；封印咒语「合入」输入路径正常
8. **构建零依赖**：game/ 目录在无网络环境直接以 file:// 打开可玩（验证无 CDN 依赖）
