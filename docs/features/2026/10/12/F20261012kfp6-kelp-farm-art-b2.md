# 獭之传说·海藻农场 P5 第二批：八田苗床模板统一 + 镜湖水体精绘

## 背景

第一批（F20261012kfp5：背景整体 + 荒田打样）经检视 delta 通过后，大獭铺开第二批派工单：其余 7 田逐块套模板 + 镜湖水体单独精绘 + 共享 helper（可维护性硬要求：chen 风格验收单还开着，返工必须有界）+ 两项收尾（CI 门禁、括号笔误）。

## 结构层：共享 helper（本单的可维护性核心）

| helper | 职责 | 参数 |
|---|---|---|
| `drawPlotFrame(x,y,w,h,kind)` | 接地影 + 3px 框环 + 三向光 | kind: wood / stone |
| `drawPlotSoil(x,y,w,h,wet,rows)` | AO 暗界 + 床土 + **连续垄沟**（跨 tile 不断，rows 显式传入）+ 固定种子土坷垃 | wet 由各田 done 态驱动 |
| `drawPlotPosts(x,y,w,h,kind)` | 四角桩：木钉扣 / 石榫头 | 画在床土之上 |
| `drawPlotPatio(x,y,w,h)` | 石坪接缝分块内面 | 老农点位专用 |

第一批 `drawPlantBed` 改写为三行 helper 调用（像素输出与第一批一致：框→床土→角桩次序与显式 rows [6,13,20,27] 保持）——**改一处 helper 八田同风格**。

## 镜湖水体

1. **渐变**：4 档量化带（`#2f6591` → `#163a63`，整像素行），上（远岸映天光）亮下（近岸深水）暗——`tileWater` 去平色底（去底后只画深水斑与波光，动画帧语义不变）

## 反泔水质检门自查

- **A1 结构同构**：八田模板是派工单指定的统一语言（打样验收后的铺开），非跨产物套模板；页面骨架不动 → 不命中
- **A2 模板换色**：本单交付物的主体恰恰是「从散写到共享结构」——helper 抽取是结构级改动，且每田内面（土/草/石）与湿态驱动各不相同 → 不命中
- **A3 风格贴皮**：wood/stone 两材质、三向光、接地影与第一批及 P0-P3 资产同纪律；镜湖新色 `#2f6591→#163a63` 由既有 w1 系色域内插，银光 `#d7ecff/#9fc4e8` 与 P.star 同族 → 不命中
- **A4 全屏均质**：八田同语言但**焦点不均质**——交互焦点田（荒田/试验田）有作物与玻璃罩叠加层，视觉密度高于装饰性庭院 → 不命中
- 观察项：B1/B2/B3/B5/B6/B7/B8 逐项过（无渐变 hero/三卡/图标堆砌/对称强迫/假数据/悬浮装饰/色相超载）
- **自我批评**：①土床内面深色系四块相近，俯视快速扫读略平——由湿态（done 变暗）与叠加演出区分，若 chen 验收要求更强区分度，第二批收尾可给休耕田加白茬秸秆点缀；②镜湖银光带为对角直线构图，略规整——散点已打散，验收若觉生硬可减带加密
