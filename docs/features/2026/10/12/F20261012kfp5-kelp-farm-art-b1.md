# Part I · P4：像素可读性根治 + visual-design 打磨

## 可读性根因（复核锚点）

| 根因 | 位置 | 机制 |
|---|---|---|
| 内部分辨率仅 480×270 | canvas width/height 属性 | 480 backing 被拉到 ~754 CSS px，image-rendering:pixelated 做 nearest-neighbor 不规则放大（1/2 CSS px 混排块，块状感） |
| 标签 7px monospace 中文 | `ctx.font = "7px monospace"` | 7px 中文字形信息量不足，任何放大都是马赛克 |
| 提示牌样式失效 | CSS 选择器 `hint-chip`（元素选择器） vs HTML `class="hint-chip"` | 选择器匹配不到，样式全失效：无浮牌形态、无定位，提示语退化为普通流式裸文本（检视实测 base 版仍以裸行可见，非「被 `overflow:hidden` 挤出视口不可见」——原归因已订正） |

## 方案设计

### A. 分辨率架构（根治层）

- `canvas width="960" height="540"`，`ctx.setTransform(2,0,0,2,0,0)`；静态烘焙层 `staticCv` 同步 960×540 并挂同 transform——**全部绘制代码留在 480×270 逻辑坐标系，零坐标改写**
- `render()` 合成改为 `drawImage(staticCv, 0, 0, W, H)`：源 960×540 → 设备 960×540，1:1 零插值
- CSS `image-rendering:pixelated → auto`：960 backing 对 ~754 CSS 是降采样（0.785×），nearest-neighbor 降采样会抽行（比原来更糟），平滑缩放把 2× 渲染采样折成干净边缘
- 点击映射 `hitSpot` 逻辑不变（恒换算回逻辑坐标）

**像素取证坐标同步**：`getImageData` 读物理像素，p2-selftest.mjs 全部采样区 ×2（闪光点/BOSS 红瞳），并新增「种子库标签物理像素存在」用例（阈值后收紧至 ≥200，检视建议）。

### B. 文字可读性（用户主诉）

- 标签/浮字：`FONT = bold 10px ui-monospace, Menlo, PingFang SC, Microsoft YaHei, monospace`——物理像素 10×2=20（原 7×1=7，近 3 倍）；CJK 字体栈显式声明
- 3px 暗色描边光晕（`strokeText` 后 `fillText`）：标签压草地纹理，对比度靠光晕拉平
- 完成勾 ✓ 改 `measureText` 实测宽度；zZz 9px、浮字带光晕；镜湖岸牌左移给 `labelBelow` 标签让位

### C. HTML UI 层（redesign：保文案/IA/品牌色，换视觉结构层）

**结构层级表**：

| 层级 | 单元 | 处置 |
|---|---|---|
| H1 级 | 画布（.screen-wrap） | 硬投影 3px 亮边框——最大最亮，1 秒动线锚点 |
| M 级 | 对话框（.dialog） | 主阅读面：14.5px/1.85 正文，teal 铭牌 tag（实心底+深墨字）作章节锚 |
| M 级 | 操作行（.actions/.btn） | 实心 teal CTA + 硬按压反馈，ghost 降级次级动作 |
| 辅级 | 状态栏（.statusbar） | 虚线分隔降噪，背包 emoji 收进 chips |
| 辅级 | HP 条（.hpbar，战斗态） | 面板化 + 分段像素纹，护盾前缘亮线 |

**风格选择**（词典+人择记录）：词典无「cozy 像素游戏 HUD」精确词条，选 **#2 新粗野主义硬边纪律** × **#6 终端/CLI 等宽纪律** × 既有夜色品牌色（teal #5fd6ae / purple #957ff0 / 夜蓝底）——结构化承载非换色。备选否决：玻璃拟态（与像素锐边冲突）、蒸汽波（色相超品牌域）。

顺手修复：`.hint-chip` 选择器 bug；`.merge input` 错误态「重新输入即复位」；删除死 CSS `.battle-acts`。

### D. P4 场景光影（poster 构图常识）

- 天空 4 色带 → 13 级量化渐变（整像素行，夜空纵深）
- 月晕 `fillRect` 方块硬边 → 径向渐变；月亮 60→200（hint-chip 修复后可见，占位左上会盖月）
- 暗角（烘焙层对象之上/标签之下，边缘 α≤0.38）：视线收束中心
- 镜湖三边暗沿柔化硬矩形切割 + 岸牌让位标签

## 取舍（诚实声明，2× 重绘 L2 挂起）

「像素颗粒物理减半」的物理边界：**美术逻辑网格仍是 480×270**——单个美术像素物理尺寸（~1.57 CSS px）由「网格 ÷ 显示宽度」决定，不随 backing 变化；物理减半需按 2× 网格密度全套重绘（L2 挂起项，等搭档拍板）。本次实际交付：① 文字物理像素 ≈3×+光晕（主诉根治）；② 每美术像素 4 采样 + 平滑缩放移除块状感；③ 升级路径留档供拍板。
