# 獭之传说·海藻农场 P6：交互体验改造（四件套）

## 诊断（来自搭档反馈 + 大獭分析）

| 症状 | 根因 | 行业对应 |
|---|---|---|
| 朋友打开一脸懵 | 无开场：没有「你是谁、要干什么」 | onboarding 缺失（星露谷爷爷的信 30 秒给目标感） |
| 「很多字、割裂」 | 下方常驻文本面板是「说明书」不是「台词」 | Show don't tell：教学融入玩法，台词短而有性格 |
| 有趣 vs 展示能力打架 | 「展示系统」压过「有趣」 | 先钩住玩家，钩住了才愿意深究 |
| 想表达什么说不清 | 能力映射只在长文本里硬塞 | 两层定位：纯玩不被打断，好奇者自选深读（codex） |

## 方案（四件套，chen 拍板「一封信+转场」）

### ① 开场信（.letter）
羊皮纸信件卡（暖纸 `#efe3c4` + 衬线体 + 微旋转 handmade 感 + teal 海獭火漆印）铺满视口，压暗背景；四段短句定世界观/目标/钩子，署名「一只从镜湖回来的獭」；CTA「收下信 · 出发 🌱」→ 淡出转场（0.36s 纯视觉，不阻塞）→ 农场。信件全文同时进图鉴（「✉️ 重读那封信」）。

### ② 气泡短台词（.dialog → 画布内上方中央浮层）
- **拆除下方常驻面板**：#dialog 连 #actions 移入 .screen-wrap 内，`position:absolute; top:46px` 上方中央字幕带——覆盖区只有天空/树线，**不遮任何可交互点位**
- **点击穿透**：气泡容器 `pointer-events:none`，仅按钮/输入框接事件（教训：mapline 也曾设 auto，elder 复读态长条吃掉了试验田的点击——selftest 抓到后已改穿透）
- **id/类名全部保留**（#dlgTag/#dlgSay/#dlgSub/#dlgMap/#actions/.merge/#battlebar）——测试断言面零破坏，只换位置与文案
- **文案瘦身**：SCRIPTS 全部 t 字段砍到 1-2 句（实测 t 字段字数 747→525 = -29.7%，t+s -21.4%；长 mapline 全文移入图鉴后屏显常驻文本归零——首版声明「约 -60%」不实，检视指出后已改为实测口径），s 保留性格句；战斗台词保留测试锚（「有獭击败过它」「洞察獭就位」「漏洞显形」「They have names」）与能力锚（search_memory / create_otter）

### ③ 獭之图鉴（#codex，可选深读层）
- topbar「📖 獭之图鉴」随时打开；intro 一句话直答「这游戏想表达什么」：**《Multi-agent system. They have names.》的可玩版**
- **收集册机制**：8 条能力映射（原 mapline 全文迁入，内容零丢失）——点亮一块田解锁一条（🔒→on）；气泡里 mapline 变短签「📖 已收录《能力名》· 图鉴里随时可查」= 收集反馈 + 教学图鉴存在
- 能力全名表 `CAPS`：记忆播种/记忆检索/上下文管理/前世封存/自愈 healing/多獭协作/异体审视/隔离试种·授权原话
- 「✉️ 重读那封信」回链开场信

### ④ 爽点反馈（juice）
能力落地：点位中心爆花 `pushSparkle ×10` + 浮字「📖 图鉴 +1」（琥珀+光晕）+ 入包 emoji 弹跳动画（`baggrow` 0.32s）+ 身份变更（setWho）。全部复用既有粒子/浮字系统，无新增等待。

## 两层定位（「游戏想表达什么」的收口）

- **纯玩家层**：信 → 点田 → 短台词 → 一键动作 → 爆花，全程无长文，不读字可通关
- **好奇者层**：图鉴里看到「这块田 = 系统能力 X」全文 + 信件世界观——答案藏在可选层，不糊脸

## 取舍与观察项

1. **气泡位置**：上方中央（字幕带）而非「跟随后点位」——点位横排密集，跟随锚点会频繁横移且在窄屏难收敛；上方带覆盖区=天空/树线，零点位遮挡，代价是偶挡云/树线（纯装饰）
2. **信前一帧**：信件显示前的静态 HTML 开场文案（pre-JS fallback）会闪现于信卡上方——保留作无 JS 降级文案，接受
3. **气泡半透明遮标签**：与气泡重叠的点位标签（如 elder/lab）在气泡期间被半透明覆盖——可点击（穿透）不受影响，验收若在意可再降气泡高度
