# 第一性三关：任务开工前的心智纪律（#1749 复盘定稿）

## 问题（事故与探讨全程）

2026-11-03 14:10 PR #1747（issue #1294）：实现者采纳 issue 建议方向一（物化 amended_by 反向字段），违反 append-only 根本原则，代价 617 处存量补登——方向性错误穿过全链质量闸，靠搭档终审拦截。复盘立案 #1749。

防再发机制探讨（chen 指令「你出方案，拉上 kimi 探讨」）：
- **v1**（大獭）：五机械机制（原则清单/触发器/句式约束/审视维度/方案分离）
- **kimichi 批判**（四条全核实成立）：根因链截断；「原则没地方查」误诊（铁律+.doc-fix+isop 假设条款早已存在，是**既有规则失效**非空白）；触发过宽；落点形式主义
- **v2/v3**（大獭）：机器信号停线 + 两段路由 + 预检门 + 代价机器事实化；kimichi delta 两轮（三阻塞→通过）
- **chen 定调（20:23，方向性修正）**：「方向还是有点不太对……更多的是心智问题：接到一件事不能直接动手就干，要敢质疑、从第一性原理出发，思考这事存不存在、方向对不对，然后才是开始做……没必要上升到机器固定代码，这更多是语义，不是数据能识别出来的」

**v3 机械闸路线废弃**（工作区 plan-1749-scheme-confirmation-v1~v3.md 留档）。决策理由：语义问题用机械方案医 = 误诊——kimichi 两轮抠触发器精度（太宽误伤/太窄漏掉）本身就是补丁摞补丁的证据。

## 方案：第一性三关（心智纪律）

接到任务（issue/派工/方案），第一动作不是动手，是过三关：

1. **这事存在吗**——前提独立核实（#1288 幽灵工单实证：「事不存在」真实发生过）
2. **方向对吗**——从第一性原理推：问题本质、候选路径、各自代价。建议方向（无论作者是否搭档本人——搭档亲提的 issue 建议同样只是输入）不构成决策；多可行方向时留取舍记录
3. **代价认了吗**——选定方向，把它自身引入的债说清楚（补登/维护/写放大），债不得写成收获（#1749 环 5：「617 债写成意外收获」）

实现中：新事实推翻前提（改变方向排序/违反验收不变量/跨 R8 级别）→ 回第 2 关重推、**交回原决策层**，禁止原方案框架内硬适配（#1749 环 2 实证）。

审视层：检视獭显式获授权质疑方案前提（B2.5）——另一颗脑袋的心智，不是机器闸。行为边界：方向存疑 → 阻塞呈报；偏好不同 → 列建议。

## R8.5 准入三问

1. **决策者变了么**：没有。三关要求的是「质疑与核实」本就是执行者义务；方向决策仍归搭档（L2）/流程；审视獭质疑权是呈报权不是裁决权
2. **靠自觉还是靠守卫**：**明示靠自觉+异体**——chen 定调「语义不是数据能识别的」，机械件为零是决策本身而非遗漏；防钝化三件（见下）如实声明为非机械手段
3. **深潜成本降了吗**：降——三关在开工入口显影方向与代价（取舍记录/前提核实留痕），替代终审时人看全量 diff 才发现方向错误
