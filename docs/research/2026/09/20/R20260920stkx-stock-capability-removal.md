# 炒股能力移除：实验复盘与决策留痕（R20260920stkx）

## 1. 背景与设想

2026-08-20 前后，炒股能力（看盘工具 stock_data + 量化纸面交易 paper_trade）上线的原始设想是：**让海獭们做量化，试试看效果**——验证 AI 多智能体在真实市场数据下的自主操盘能力。若验证有效，则接入更正式的环境。

搭档 2026-09-20 16:04 原话（决策留档）：

> 「我一开始设想就是让海獭们做量化，试试看效果。结果呢，也上线一个月了吧，基本啥也没干，天天这有问题哪有问题，我记得应该就只买入了三次。……目前这么个效果，我都想直接移除当前能力了，感觉毫无作用。原本就想着只是验证，如果有点东西，就直接接入所谓正式点的环境，但现在来看，海獭根本做不好，不如先完整移除掉算了。」

## 2. 一个月实绩数据（大獭核实）

|------|------|

| 持仓 | 000001×3000 / 300750×100 / 600519×100 |

## 3. 败因分析

结论定性：**AI 操盘败于「数据链稳定性 + 主动性缺失」**——两者互为放大器，形成全静默死亡闭环。

### 3.1 数据链稳定性败因（外部依赖脆弱）

- **akshare 依赖东财域名**：2026-09-01 起持续拒连（上游接口不稳定，第三方数据源无 SLA）
- **Python venv 环境事故**：`.venv-stock` 9/17 17:22 变成指向自己的循环符号链接，坏死后 **3 天无人察觉**——因为根本没东西在用它
- 服务端解析链 `STOCK_PYTHON > .venv-stock/bin/python > python3` 三级全灭，仅 quote（新浪 HTTP 直连）存活

### 3.2 主动性缺失（AI 侧败因）

- 定时任务只按 prompt 模板执行买入流程，无自主风控、无自主调仓、无异常响应
- 持仓价格停在成本价 9 天无告警、无自愈动作——**环境坏→无数据→不决策→无产出→无人发现**，闭环全静默
- 「上线一个月只触发 3 次买入且全部来自同一定时任务」说明：系统没有形成任何超出模板脚本的行为，AI 操盘的「智能」成分未被验证

### 3.3 闭环全静默的结构性问题

两笔账合起来看：数据链坏了 19 天（akshare 拒连起），系统没有产生任何「我坏了」的信号；venv 坏了 3 天无告警。**一个不能报告自身健康的自治系统，等于没有自治**——这是比「亏钱」更根本的失败：连亏钱的资格都没挣到。

## 5. 如果未来重启的先决条件

这次实验的核心教训不是「AI 不会炒股」，而是**验证顺序反了**——先上了操盘能力，数据链可靠性从未被验证。未来重启（无论 AI 操盘还是接正式环境）的先决条件按优先级：

1. **数据链可靠性优先于策略能力**：主数据源 + 备源 + 健康探针三件套先行，探针挂了必须产生人可见的告警（healing/issue），静默失败 = 系统不存在
2. **环境依赖最小化**：Python venv 这类易腐环境需纳入 daily-health-check 巡检面（本次 venv 自循环链接 3 天无人察觉即巡检盲区实证）
3. **主动性度量前置**：上线前定义「AI 自主行为」的最低期望（如 N 次/周的非模板决策），低于期望线自动触发复盘，而不是等搭档一个月后凭印象问「是不是就买了三次」
4. **实验期限与退出标准显式化**：验证型能力上线时写明「什么结果算失败、失败后何时撤」，避免失败能力长期挂机占维护成本
