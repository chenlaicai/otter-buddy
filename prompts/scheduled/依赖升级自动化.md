## 任务：依赖升级自动化

### 目标
检查 GitHub 上 Dependabot 创建的依赖升级 PR，关闭这些 PR，然后按照研发流程创建统一的依赖升级 PR。

### 执行步骤

#### 1. 检查 Dependabot PR
```bash
gh pr list --author "dependabot[bot]" --state open --json number,title,headRefName
```

#### 2. 如果有 Dependabot PR
- **关闭所有 Dependabot PR**：
  ```bash
  # 对每个 PR 执行
  gh pr close {PR_NUMBER} --comment "已合并到统一的依赖升级 PR"
  ```

- **删除 Dependabot 创建的分支**：
  ```bash
  gh api repos/{owner}/{repo}/git/refs/heads/{branch} --method DELETE
  ```

#### 3. 创建统一的依赖升级 PR
- **创建 worktree**：
  ```bash
  # 按照 worktree-isolation skill 的流程
  ```

- **执行依赖升级**：
  ```bash
  npm update
  ```

- **提交代码**：
  ```bash
  # 按照研发流程格式提交
  git add package.json package-lock.json
  git commit -m "[F{date}NNN][deps][Feature Update] 统一升级依赖版本"
  ```

- **创建 PR**：
  ```bash
  gh pr create --title "[deps] 统一升级依赖版本 ({date})" --body "..."
  ```

#### 4. 通知搭档
- **发送通知**：告诉搭档 PR 已创建，等待检视

### 注意事项
- 按照研发流程提交
- 主版本升级需要单独创建 PR，添加警告标记
- 不自动合并，等待搭档合入
